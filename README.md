# Gurukul Library

Static HTML, CSS, and JavaScript website for Gurukul Library.

## Deploy with Vercel

This repository is configured with `vercel.json` for a static deployment. Import this GitHub repository in Vercel and keep the Framework Preset as **Other** and the Root Directory as the repository root. No build command is required. Vercel will redeploy when you push updates to the connected branch.

See [DEPLOY-VERCEL.md](DEPLOY-VERCEL.md) for setup details.

The membership application runs in the browser and sends its details to WhatsApp. Uploaded files are not stored on a server; the member attaches them in WhatsApp.
